# 贵族 The Aristocrat —— 杀戮尖塔2 移植版

把《杀戮尖塔》一代的角色 mod **贵族（The Aristocrat）** 移植到《杀戮尖塔2》。

原 mod 由 **2D20** 制作。本仓库只做移植，卡牌名称、卡图、效果设计均沿用原作。

## 目前进度

- 卡牌：一代的 80 个卡牌类已全部搬完（含 2 张自制先古卡，卡池共 78 张）
- 遗物：2 / 11（家族纹章、家族荣誉）
- 商店机制：首战替换商店、精英战后开商店、商店折扣，均已实现并支持存读档
- 特典（Perk）系统：自定义关键词 + 购买触发钩子
- 先古之民：已接入奥罗巴斯（初始遗物/初始卡牌的先古升级）与达夫（尘封魔典）

## 怎么编译

需要：

- 《杀戮尖塔2》本体
- [.NET 9 SDK](https://dotnet.microsoft.com/download)
- Godot 4.5.1 **Mono** 版（导出 pck 用）
- 前置 mod **BaseLib**（运行时要装，编译时要把它的 `BaseLib.dll` 放到 `libs/` 下）

步骤：

1. 打开 `Aristocrat.csproj`，把 `Sts2Dir` 改成你自己的游戏目录，把 `GodotExe` 改成你的 Godot 路径。
2. 把 BaseLib 的 `BaseLib.dll` 复制到 `libs/`。
3. 编译并自动复制到游戏 mods 目录：

   ```
   dotnet build
   ```

4. 导出资源包（卡图、本地化文本都靠它进 pck）：

   ```
   dotnet build -t:ExportPck
   ```

5. 启动游戏，选人界面就会出现「贵族」。

## 已知问题

- 「肖像」特典给的「固有」是永久效果，但塔2 的卡牌存档里不含关键词，中途存档读档后可能会掉
- 多人联机完全没有测试
- 战斗中的角色模型目前借用铁甲战士（原 mod 是 Spriter 动画，塔2 用 Spine，需要重做美术资源）
